# SusPak - Enactus IIT Bombay

Pioneering a future where packaging heals the planet.

## About

SusPak is a sustainable packaging solution by Enactus IIT Bombay, creating biodegradable food packaging from sugarcane bagasse and wood pulp.

## Features

- 100% Compostable (30-90 days)
- Heat Resistant up to 150°C
- Cost-competitive (1.3-1.5x plastic)
- Water resistant coating
